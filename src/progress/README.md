# `src/progress/` — motor de progreso

Motor compartido (Fase 3) donde **todas** las preguntas, quizzes, juegos y retos registran sus resultados: aminoácido, habilidad, acierto y tiempo.

Alimenta el repaso espaciado, los niveles, las insignias y el mapa de dominio. Guarda en `localStorage` (siempre con try/catch) y permite exportar/importar el progreso como JSON. Ninguna pestaña guarda progreso por su cuenta.
