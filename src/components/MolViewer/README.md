# `MolViewer` — visor 3D compartido

Componente único, basado en **3Dmol.js**, que usan todas las pestañas para mostrar aminoácidos sueltos y proteínas. Se construye por niveles a partir de la Fase 1.

Incluye (según avance el plan): representaciones, modos de color, nube de carga (potencial de Coulomb aproximado, en Web Worker), superficies, interacciones, choques estéricos, medidas, etiquetas, barra de secuencia, captura PNG y compartir vista por enlace. Cada opción explica en 1–2 frases qué enseña.

Si una pestaña necesita una vista nueva, se agrega aquí, no en un visor aparte. Respeta la regla anti-spoiler en modo quiz.
